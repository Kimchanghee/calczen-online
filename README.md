**금융**: 주택담보 LTV/DTI/DSR · 신용대출 한도 · 마이너스통장 이자 · 자동차 할부 · 학자금 대출 · 적금 vs 예금 · 복리 · 채권 수익률 · 환차익

**세금**: 종합소득세 · 양도세 · 증여세 · 상속세 · 부가가치세 · 원천징수 · 종합부동산세 · 취득세

**노동**: 연봉 실수령액 · 시급/일급/월급 변환 · 퇴직금 · 실업급여 · 연차수당 · 야근수당 · 4대보험 · 직장가입자 건보료

**일상**: BMI · 칼로리 · 단위 변환 · 임신 주수 · 디데이 · 나이 · 윤년

## 기술 스택

- **Astro 5** (정적 SSG, 100% pre-rendered)
- **Tailwind CSS**
- **Vanilla TypeScript** (계산기 로직)
- 현재 계산은 브라우저 안에서 실행되며 외부 API나 서버 런타임이 필요하지 않습니다.

## SEO

- 50개 계산기 × 시나리오별 페이지(예: "연봉 5천만원 실수령액") = 300+ 진입점
- 내부 링크: 계산기 간 관련 추천("연봉 → 퇴직금 → 4대보험" 체인)
